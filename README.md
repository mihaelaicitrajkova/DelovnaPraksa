# Мостари

Мостари е демо-страница за фиктивна граѓанска организација од Скопје. Таа е прво на македонски, со едноставен прекинувач за англиска верзија.

## Што е изработено

- Воведна страница со современ, уреднички изглед и топла портокалово-зелена палета.
- Оригинална илустрација на маало изградена само со CSS, без надворешни слики.
- Секции за активна акција, мерлив ефект, три програмски области, приказна и контакт.
- Поврзани подстраници за „За нас“, сите три програми, активната акција, вклучување и три измислени приказни од маалото.
- Респонзивен распоред за телефони и пристапни навигациски ознаки.
- Македонски и англиски содржини, со македонски како почетен јазик.

## Технологии

- Next.js и React за страницата и интеракциите.
- Tailwind CSS за основниот стилски слој, со прилагоден CSS за уникатниот изглед и илустрации.
- Vinext / Vite конфигурација подготвена за лесно објавување.

## Локално стартување

Потребен е Node.js 22 или понов.

```bash
npm install
npm run dev
```

За продукциска проверка:

```bash
npm run build
```
